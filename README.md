# seien

A desktop avatar that asks you to do your tasks and cheers you on

## Development

- `mise install` installs the tool versions from `.mise.toml`.
- `bun install`
- `node node_modules/electron/install.js` fetches the Electron binary after `bun install`.
- `bun run dev`
- `bun run test`
- `bun run e2e` needs a display on Linux; use `xvfb-run -a bun run e2e`.
- `bun run dist`
